<h1 align="center">BIFROST</h1>

<p align="center">
  Self-hosted Git platform for repositories, issues, pull requests, CI/CD, packages, teams, and developer workflows.
</p>

BIFROST is a self-hosted Git platform for repositories, issues, pull requests, CI/CD, packages, teams, and developer workflows.

## Planned Stack

- Next.js, React, TypeScript, Tailwind CSS
- CodeIgniter 4, PHP 8.4
- Node.js, Socket.IO, Redis
- MariaDB
- Cloudflare R2
- Docker, OpenLiteSpeed, Cloudflare
- BIFROST Runner
- Windows and Linux desktop app
- AI-generated commit and pull request summaries

## Planned Repositories

- `bifrost-web`
- `bifrost-api`
- `bifrost-realtime`
- `bifrost-runner`
- `bifrost-desktop`
- `bifrost-sdk`
- `bifrost-ui`
- `bifrost-infra`
- `bifrost-docs`
- `bifrost-design`
